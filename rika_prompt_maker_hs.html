🧪 先生のためのAI活用研修ツール

高校理科 プロンプトメーカー

学年・科目・単元・教材の種類を選ぶだけで、生成AIに貼り付けるための「プロンプト(指示文)」を自動でつくります。プログラミングの知識は不要です。単元は高等学校学習指導要領(平成30年告示)の科目・内容に沿って構成しています。できあがったプロンプトを生成AI(Claude・ChatGPT・Geminiなど)に貼り付けると、担当科目に合ったHTML教材が生成されます。

1

対象学年を選ぶ

学年を選ぶと、その学年で標準的に開講される科目が上に表示されます(履修学年は学校により異なります)。

2

📋 生成されたプロンプト 

  


  

    次にすること
    
    
      
  1. 上の「コピーする」ボタンでプロンプトをコピーします。
    2. 
      
  2. 生成AI(Claude・ChatGPT・Geminiなど)のチャット欄に貼り付けて送信します。
    3. 
      
  3. 生成されたHTMLコードを「メモ帳」などに貼り付け、「〇〇.html」という名前で保存します(Claudeの場合はプレビューがそのまま表示されます)。
    4. 
      
  4. 保存したファイルをダブルクリックすると、ブラウザで教材が開きます。
    5. 
      
  5. 直したいところがあれば、続けて「この設問を難しくして」「グラフを追加して」のように日本語で頼めば修正できます。
    6. 
    

  


  

    
💡 うまくいくコツ

    
    
      
  1. 一度で完璧を目指さず、「生成 → 試す → 直してもらう」を繰り返すのがコツです。
    2. 
      
  2. 生成された内容(用語・数値・化学式・実験手順・計算過程)は、必ず教科書や資料集と照らして確認してから授業で使いましょう。生成AIは誤りを含むことがあります。
    3. 
      
  3. 「その他の要望」に生徒の実態や重点を書くと、より狙いに合った教材になります。
